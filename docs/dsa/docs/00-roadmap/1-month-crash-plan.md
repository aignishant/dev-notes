# 📅 1-month crash plan

> 30 days. ~500 problems. 8 hours per day. The emergency, all-in plan.

---

## Who this plan is for

✅ You have **30 days** (or close to it) until a critical interview.
✅ You can do **8 hours per day** for 30 straight days (took leave, between jobs, between semesters).
✅ You have **at least beginner basics** — comfortable writing a Python loop, function, list comprehension.

If your basics aren't there, this plan won't work. Pick **6-week thorough** and ask the recruiter for an extension.

---

## The bargain this plan makes

| Buy | Cost |
|---|---|
| All 20 patterns + core DS covered | Less retention than longer plans |
| 500 problems | Heavy fatigue risk in week 4 |
| 5 mock interviews | Minimal system design (1 only) |
| Speed = priority over depth | You will forget some material; refresh in final week |

---

## Daily rhythm (8-hour day)

```
07:00 — wake, exercise, breakfast
08:00 — block 1 (1 hr): morning re-do — 2 problems from memory
09:00 — block 2 (2 hrs): read topic chapter + 3 problems
11:00 — break (1 hr)
12:00 — block 3 (2 hrs): 4 more problems
14:00 — lunch + walk (1 hr)
15:00 — block 4 (2 hrs): 3 problems + 1 timed problem (no peeking)
17:00 — log progress, snack
18:00 — block 5 (1 hr): re-read weakest concept of the day, light reading
19:00 — dinner, off
22:00 — sleep
```

Target: 8–10 problems/day on weekdays, 6 on weekends (rest more on weekends — endurance).

## The "must-do 100" core list

Across the 30 days, these 100 problems are non-negotiable:

- **Arrays (15):** Two Sum, Best Time to Buy/Sell Stock, Maximum Subarray (Kadane), Container With Most Water, 3Sum, Trapping Rain Water, Subarray Sum Equals K, Product of Array Except Self, Move Zeroes, Rotate Array, Find Min in Rotated Sorted, Search in Rotated Sorted, Merge Sorted Array, Median of Two Sorted Arrays, First Missing Positive
- **Strings (10):** Valid Anagram, Group Anagrams, Longest Substring Without Repeating, Longest Palindromic Substring, String to Integer (atoi), Valid Palindrome, Minimum Window Substring, Word Break, Edit Distance, Decode Ways
- **Hash (5):** Two Sum, Group Anagrams, Top K Frequent, LRU Cache, Longest Consecutive Sequence
- **Linked Lists (8):** Reverse, Detect Cycle, Merge Two Sorted, Merge K Sorted, Reverse Nodes in K-Group, Remove Nth From End, Copy with Random Pointer, Reorder
- **Stacks (5):** Valid Parentheses, Min Stack, Daily Temperatures, Largest Rectangle Histogram, Decode String
- **Trees (12):** Inorder, Preorder, Postorder, Level Order, Max Depth, Validate BST, Lowest Common Ancestor, Diameter, Path Sum III, Serialize/Deserialize, Construct from Preorder+Inorder, Right Side View
- **Graphs (10):** Number of Islands, Clone Graph, Course Schedule I + II, Pacific Atlantic, Word Ladder, Network Delay Time, Cheapest Flights with K Stops, Min Cost to Connect Sticks, Critical Connections
- **DP (15):** Climbing Stairs, House Robber I + II, Coin Change, Word Break, Longest Increasing Subsequence, Edit Distance, LCS, Unique Paths, Min Path Sum, Decode Ways, Best Time IV (with cooldown), Burst Balloons, Maximum Profit Knapsack, Partition Equal Subset Sum, Regular Expression Matching
- **Backtracking (8):** Subsets, Permutations, Combinations, Combination Sum, Word Search, N-Queens, Sudoku Solver, Generate Parentheses
- **Heap (5):** Top K Frequent, Find Median from Data Stream, Merge K Sorted Lists, K Closest Points to Origin, Task Scheduler
- **Misc (7):** Sort Colors, Spiral Matrix, Set Matrix Zeroes, Game of Life, Insert Interval, Merge Intervals, Meeting Rooms II

If you can solve 80+ of these without peeking by day 28, you're interview-ready for most product company onsite rounds.

---

## Falling behind?

After day 14:
- <100 problems → drop week 4's "all 20 patterns re-read" and use that day to grind your weakest topic
- <70 problems → drop system design entirely; focus on coding only
- <50 problems → reschedule the interview if at all possible
