# Progress tracker

> Print this. Tape it on your wall. Update weekly.

---

## How to use

This page is a set of checklists. Don't try to fill all of them at once. Update **once a week** for 15 minutes. That's enough to see trends and adjust.

The tracker has 5 parts:

1. **The honest baseline** — where am I starting from?
2. **Topic mastery checklist** — am I covering every topic the bible covers?
3. **Problem count tracker** — am I solving enough problems?
4. **Confidence rating** — how do I feel about each topic?
5. **The "ready to interview" checklist** — am I actually ready?

**Self-grade rubric (out of 10):**
- 2 pts — clarification + brute-force first
- 2 pts — pattern recognition + insight communicated

- 2 pts — clear final summary

If you score >7 consistently across 3 mocks, you're interview-ready.

## Part 6 — The "ready to interview" checklist

When you can tick **all** of these, you're ready. Not before.

- [ ] I have solved 300+ problems with at least 30% re-do
- [ ] I can solve a fresh medium in <30 min, talking the whole time
- [ ] I can solve a fresh hard in <60 min, with some hints
- [ ] I have done 6+ mock interviews, scoring >7/10 on the last 3
- [ ] I know all 20 patterns and can name them on sight
- [ ] I have completed 1+ Tier-1 system design project (if interviewing senior+)
- [ ] I have 5+ STAR stories rehearsed
- [ ] I have a 90-second "tell me about yourself" rehearsed
- [ ] I have read this bible's [Interview stages explained](interview-stages-explained.md)
- [ ] I have re-read the [Big-O cheatsheet](../01-foundations/big-o-cheatsheet.md) at least 3 times

## Weekly review template (15 min, every Sunday)

- [ ] Update problem count for the week
- [ ] Update confidence ratings if month-end
- [ ] Identify weakest topic of the week
- [ ] Plan next week's first 3 days
- [ ] One sentence: what did I learn that I can apply forever?
- [ ] One sentence: what was hardest, and why?

That's it. 15 minutes weekly = the most valuable 15 minutes of the week.
