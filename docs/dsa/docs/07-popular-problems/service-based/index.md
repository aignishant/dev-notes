## 🏢 What interviewing at service companies is like

The shape is essentially the same — only volume / branding changes.

| Round | Length | Focus |
|---|---|---|
| **Aptitude (online)** | 60-90 min | Quant + logical reasoning + verbal + sometimes coding MCQ. |
| **Coding round (online)** | 60 min | 1-2 problems, easy / medium. Sometimes pseudocode acceptable. |
| **Technical interview ×1-2** | 30-45 min each | DSA basics + DBMS + OS + OOP + project. |
| **HR / managerial** | 20-30 min | Communication, willingness to relocate, bond, "why this company". |

**Key facts**:
- Most have a **service bond** (1-2 years, ₹50k-₹2L penalty if you leave early). Read carefully.
- Hiring is **mass-hire** — throughput matters more than depth. The bar is achievable for any disciplined CS / IT student.
- Slight variation: **Zoho** is closer to a product company in interview style (multiple coding rounds, harder problems, no bond). Treat its prep more like product-based.

## 🔬 Three deep-dives (most-asked coding patterns)

### Deep-dive 1 — Reverse a Linked List

??? question "Story: classic. Asked at literally every service-company tech round."

```python
class Node:
    def __init__(self, val: int, nxt: "Node | None" = None):
        self.val = val
        self.next = nxt

def reverse(head: Node | None) -> Node | None:
    prev: Node | None = None
    curr = head
    while curr is not None:
        nxt = curr.next
        curr.next = prev
        prev = curr
        curr = nxt
    return prev
```

??? abstract "Complexity"

    O(N) time, O(1) space. Memorise this and write it without a pause.

??? tip "Follow-up: reverse recursively"

    ```python
    def reverse_rec(head):
        if head is None or head.next is None:
            return head
        new_head = reverse_rec(head.next)
        head.next.next = head
        head.next = None
        return new_head
    ```

### Deep-dive 2 — Find a number in a rotated sorted array

??? question "Story: array sorted then rotated by some amount. Search in O(log N)."

```python
def search_rotated(nums: list[int], target: int) -> int:
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        # left half is sorted
        if nums[lo] <= nums[mid]:
            if nums[lo] <= target < nums[mid]:
                hi = mid - 1
            else:
                lo = mid + 1
        else:  # right half is sorted
            if nums[mid] < target <= nums[hi]:
                lo = mid + 1
            else:
                hi = mid - 1
    return -1
```

??? abstract "Complexity"

    O(log N). The key insight: at every step, **at least one half is sorted** — decide which, then check if the target lies in that half.

### Deep-dive 3 — Print all permutations of a string

??? question "Story: classic recursion / backtracking warm-up. Tests whether you can think recursively."

```python
def permutations(s: str) -> list[str]:
    out: list[str] = []
    chars = list(s)

    def backtrack(start: int) -> None:
        if start == len(chars):
            out.append("".join(chars))
            return
        for i in range(start, len(chars)):
            chars[start], chars[i] = chars[i], chars[start]
            backtrack(start + 1)
            chars[start], chars[i] = chars[i], chars[start]  # undo

    backtrack(0)
    return out
```

??? abstract "Complexity"

    O(N · N!) — N! permutations × N to copy the string.

??? tip "Follow-up: dedupe when input has repeats"

    Sort first, then in the loop skip `i > start and chars[i] == chars[start]` after the swap-back. Or use a `set()` of starts at each level.

## 🛡️ Day-of tips

- **Aptitude is gateway**: no aptitude clear, no further rounds. Burn 10 days on IndiaBix before anything else.
- **Speak slowly + correctly**: communication is graded openly. Hesitation is fine; word salad is not.
- **Respect the bond**: if you mention you'd leave early, the offer disappears.
- **Be polite**: HR rounds reject more candidates than tech rounds. Smile, don't argue, ask one good question at the end.
- **Zoho is different**: skip the aptitude focus, drill product-style coding instead.
