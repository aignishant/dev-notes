# 🎤 Mock Interviews

> Full-length transcript-style mock interviews you can read like a script.

<span class="phase-status phase-pending">Phase 14 — Pending</span>

When this section is built, it will hold:

- **5+ full mock interview transcripts** — DSA round, system design round, behavioral round
- For each one: the interviewer's questions, the candidate's answers, **what was good, what was weak, and how to do it better**
- A **mock interview self-grading rubric** (problem comprehension, code clarity, optimization, communication, follow-up handling, edge cases)
- Tips for live mocks on Pramp / interviewing.io

This section is a *complement* to live human practice — not a replacement. The bible can teach concepts, problems, and design; for the conversational rhythm of an interview, you still want a real human across the table. The mocks here let you study the *form* of a great interview before you book one.
