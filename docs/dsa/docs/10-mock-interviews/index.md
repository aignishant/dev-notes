> Full-length transcript-style mock interviews you can read like a script. Each one shows the *rhythm* — when to slow down, when to push, when to accept "good enough."

## 🎯 How to use this section

1. **Read all four transcripts cover-to-cover** before doing any live mocks. The transcripts show what "good" sounds like; live mocks let you practice it.
2. **Score yourself with the rubric** after every mock — your own or with a partner. Pick one weak row per mock; don't try to fix everything.
3. **Follow the live-mocks operating manual** — booking cadence, the post-mock 30-min review, the two-week pre-onsite sprint.

The compounding effect is real. Six mocks with disciplined post-mock review beats sixty mocks of pattern-grinding.
