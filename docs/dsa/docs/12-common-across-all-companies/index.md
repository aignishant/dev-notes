## ⚡ How to use this section

3. Time-box each page: 1 hr to skim + identify gaps, then 4-6 hr of solving across a week.

If you only had two weeks total, these 16 pages plus the corresponding [pattern templates](../13-resources/03-pattern-templates.md) would give you the highest ROI of any prep schedule.
