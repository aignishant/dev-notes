## 🃏 Skim before every interview

<div class="grid cards" markdown>

-   :material-clock-fast: **[Big-O Cheatsheet](01-big-o-cheatsheet.md)**

    ---

    Every data structure, every operation, average + worst case. Sort algorithms, graph algorithms, DP shapes. The "input size → bound" table for choosing the right approach.

-   :simple-python: **[Python STL Cheatsheet](02-python-stl-cheatsheet.md)**

    ---

    `collections`, `heapq`, `bisect`, `itertools`, `functools`, `math`. The six imports that cover 95% of interviews. Idioms, anti-patterns, the `[[0]*n]*m` trap.

-   :material-code-braces: **[Pattern Templates](03-pattern-templates.md)**

    ---

    Copy-paste-ready skeletons for two pointers, sliding window, BFS/DFS, binary search, backtracking, DP, union-find, trie, heap, linked list. Memorise the shape; fill in the body.

## ⚡ The fastest tour

If you only have 30 minutes with this section:

1. Read the **Big-O cheatsheet** input-size table — it answers the "what algorithm" question.
2. Read the **Python STL** "memorise these import lines" section.
3. Skim the **Pattern Templates** for any pattern you can't write from memory.
4. Bookmark the **Glossary** for when you hit an unfamiliar term elsewhere.

The other four pages reward time over weeks, not minutes.
