## How to Use This Guide

!!! tip "The 3-Pass Method"
    **Pass 1 (Day 1–2) — Read everything.** Don't try to memorize; just absorb the narrative. Most questions build on the previous one.

    **Pass 2 (Day 3–5) — Practice aloud.** Open each question and explain the answer to an imaginary interviewer *without looking*. If you stumble, re-read and repeat.

    **Pass 3 (Day 6–7) — Mock rounds.** Do the 3 mock interviews in the last module under timed conditions. Review gaps. Revisit the rapid-revision sheet.

## What Makes This Guide Different

- **Every answer has an analogy** — because interviewers don't want textbook definitions, they want to see you *understand* it.
- **Every concept has a scenario** — the real interview isn't "define bias." It's "your model has 95% train accuracy and 70% test accuracy. Debug it."
- **Every formula is explained in plain English** — you'll know *why* it works, not just the symbols.
- **Python-first code** — short, readable, runnable snippets (scikit-learn, NumPy, pandas).

## Interview Reality Check

!!! warning "What Interviewers Actually Test"
    **60% — Can you explain the concept simply?** If you use jargon to hide confusion, they'll see it.

    **25% — Can you connect it to a real problem?** "Fraud detection with 0.1% positive class" is a variance/imbalance question in disguise.

    **15% — Can you write minimal code?** Not a full notebook — 10 lines showing you *could* implement it.

## Prerequisites

You should already be comfortable with:

- Python (numpy, pandas, scikit-learn basics)
- High-school calculus (derivatives) and linear algebra (matrices)
- Basic statistics (mean, variance, distributions)

If any of those are shaky, do a 2-day refresh first — the questions here assume fluency.
